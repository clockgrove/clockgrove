# Domain seams

This package contains provider-neutral domain vocabulary only. It performs no I/O and owns no
simulation, scheduling, route search, placement, persistence, rendering, or process execution.

## Subsystem contracts

- [Spatial](docs/spatial.md): frames, regions, anchors and movement records.
- [Environment](docs/environment.md): environment policy and state.
- [Ecology](docs/ecology.md): ecology policy and state.
- [Wellbeing](docs/wellbeing.md): wellbeing policy and state.
- [Utility](docs/utility.md): utility policy and scripted cognition.
- [Lifecycle](docs/lifecycle.md): lifecycle policy and state.
- [Rules](docs/rules.md): rule primitives.
- [Components](docs/components.md): components and the physical world adapter.
- [Component catalog](docs/component-catalog.md): the bounded component catalog.
- [Component composition](docs/component-composition.md): versioned components and pinned composition.
